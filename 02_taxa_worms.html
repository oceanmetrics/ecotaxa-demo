A reviewable lookup table, with explicit rules for what is not a taxon

Rules

Category Rule Result
root not-living or temporary (detritus<not-living, t001) never an occurrence excluded
phylogenetic (type P) with an aphia_id on the node use it, verify in WoRMS, publish under the valid name aphia
phylogenetic without an aphia_id exact name match in WoRMS; no hit stops the build name_match / unresolved
morphological under Biota (egg<other, nauplii<Cyclopoida) nearest ancestor with an aphia_id, unless it is only Biota ancestor / excluded

The decision is pure and tested without the network (tests/testthat/test-taxa.R); WoRMS is injected, so the same code runs against a canned WoRMS in the tests and against worrms here.

## Rules

| Category | Rule | Result |
|---|---|---|
| root `not-living` or `temporary` (`detritus<not-living`, `t001`) | never an occurrence | `excluded` |
| phylogenetic (type P) with an `aphia_id` on the node | use it, verify in WoRMS, publish under the valid name | `aphia` |
| phylogenetic without an `aphia_id` | exact name match in WoRMS; no hit stops the build | `name_match` / `unresolved` |
| morphological under Biota (`egg<other`, `nauplii<Cyclopoida`) | nearest ancestor with an `aphia_id`, unless it is only Biota | `ancestor` / `excluded` |

The decision is pure and tested without the network (`tests/testthat/test-taxa.R`); WoRMS is injected, so the
same code runs against a canned WoRMS in the tests and against `worrms` here.
