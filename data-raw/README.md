# data-raw

`import_test/` is the upstream EcoTaxa test import set (`ecotaxa_back/QA/py/data/import_test.zip`,
https://github.com/ecotaxa/ecotaxa_back): two Zooscan samples, eight objects with images, in the EcoTaxa
TSV format. It is the same set that was imported into project 2 ("US EcoTaxa demo") on
https://ecotaxa.oceanmetrics.io, so `01_export_ecotaxa.qmd` can run without a login against a byte-identical
stand-in for the export. Copied 2026-11-06; EcoTaxa is GPL-3.
